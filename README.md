## 📌 What is This?

🕹️ A fully responsive **Typing Speed Test** built using **HTML, CSS & Vanilla JS** — no frameworks, no backend, just raw frontend power.  
💻 Retro terminal UI + glowing vibes + voice & AI integration.

## 🛠️ Tech Stack

| ⚙️ Tech          | 🚀 Usage                                |
| ---------------- | --------------------------------------- |
| HTML5 / CSS3     | Terminal UI, layout, themes             |
| JavaScript (ES6) | Game logic, typing engine               |
| Canvas API       | Animated matrix rain background         |
| Speech API       | Voice to text for typing via microphone |
| Web Audio API    | Keypress & win/error feedback           |
| LocalStorage     | Theme + sound preference persistence    |
